## Notes
Done 2026-11-21.
- **Engine (`@ndpa/scan-engine`):**
  - `collectEvidence()` runs PRD §5.1 steps 1–8: preflight, homepage capture, discovery from its links, then every page in none/reject/accept (2 in parallel), plus a mobile homepage pass. It also extracts the policy text and maps third-party flows (resolved and geolocated through an injectable `geo`).
  - It returns a plain-JSON `EvidenceBundle` (`ndpa-lens/bundle@1`, `ENGINE_VERSION` 1.0.0) in a stable order. One page failing doesn't sink the scan; the homepage must succeed.
  - Capture now returns links and the policy link. The HTML is kept in memory only and stripped from the bundle.
  - New `ignoreTlsErrors` option: certificate problems become findings (C-19) rather than aborted scans.
  - Preflight accepts a test CA.
  - `discoverFromLinks` split out of `discoverPages`.
- **Retention rule fix:** the NDPA retention rule missed plain statements like “we retain records for six years”. It now accepts a stated period, with a test. This also fixes a false negative in the legacy scanner.
- **`@ndpa/checks`:**
  - C-01..C-10 are pure functions over the bundle, each with a version, area, severity and a draft legal reference marked *pending legal review*.
  - `runChecks` stamps provenance (check, engine and vendor-list versions). The same bundle always gives the same findings in the same order. A crashing check becomes a needs-review finding.
  - C-08 gives one finding per required policy item (6). C-10 uses the server's country and falls back to the vendor's HQ. Unknown third-party scripts before consent become needs-review, never a pass.
- **Goldens:** `pnpm --filter @ndpa/checks golden:capture` captures real bundles from all 21 fixture variants into `golden/` (2.7 MB, ports normalised). CI runs the checks over them with no browser.
  - A test fails if a golden was captured by an older `ENGINE_VERSION`, so bump the version and recapture when capture changes.
- **Proof:** `pnpm turbo run typecheck build test` over the affected packages passed (19 tasks).
  - `@ndpa/checks`: 24 tests. Each variant's labelled C-01..C-10 expectation is met, and the baseline passes all of them.
  - Variants built for C-11..C-20 produce no failures in C-01..C-10.
  - Determinism, provenance and evidence hashes are checked, and a crashing check is contained.
  - Engine: 39 tests.
- **Not verified / risks:**
  - The fixtures are a controlled site. Real-world precision (PRD §12: ≥90% on the 300-site sweep) needs the owner's labelled sweep.
  - Legal references are drafts.
  - C-04 thresholds (reject smaller than half the accept button's area, or text more than 2px smaller) are a judgment call for the legal reviewer to confirm.
